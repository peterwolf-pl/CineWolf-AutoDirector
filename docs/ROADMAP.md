# Roadmap

## Version 2.0.0 — complete (Flashback-only production platform)

- Stronger Flashback adapter boundary, capability model, and compatibility registry.
- Soft Flashback dependency (safe load when missing/unsupported).
- Public CineWolf Integration API 2.0 with isolated registration.
- Advanced vehicle profiles and soft PeterWolf train/plane/zipline providers.
- Local community preset library and secure bundles.
- Replay-bound project schema v2 with migration, autosave, and recovery.
- Montage Engine 2.0 style/narrative/diversity/vehicle planning.
- Diagnostics v2 with redaction and timeline/integration records.
- Explicitly no ReplayMod support.

## Version 2.1 (recommended)

- Deeper UI panels for project library, preset browser, and integration diagnostics.
- Optional native Flashback timeline glyphs only if Flashback publishes a stable extension surface.
- Expanded multi-entity train sampling when connected carriages are queryable.
- Performance profiles for very long replays (streaming analysis windows).
- Additional vehicle templates and structure-scale framing polish.
- Broader Flashback patch-range validation once upstream APIs stabilize.

## Deliberately out of scope

- ReplayMod support, adapters, conversion, mixins, docs, or dependencies.
- Cloud preset catalogs, accounts, telemetry, or remote AI services.
